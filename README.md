# 漂流港 · Driftport

七章航行、两片开放海域与九重门藏。由数学与物理经典启发的探索游戏。

## 操作

- 电脑：WASD / 方向键驾驶，Space 交互，Shift 减速；鼠标拖镜、投信。
- 平板 / 手机：按住海面驾驶，触点离船越远越快；松手停船。轻点近处对象交互，轻点远处短途驶近。声纳轻点船身记录测线；拖镜片调整反射，轻点瞄准光点投信。建议横屏。
- 海图：点击图标可查看地名；点击下方地点名会在图上标出位置，再点“驶向所选地点”导航。
- 护航涂层：每层持续三分钟并减伤三分之一；不同商贩的效果线性叠加，三层免伤。买过的商贩会在本层到期前暂停售卖。
- 暂停菜单可切换触控显示。手记、海图随剧情解锁。

## 存档

进度保存在当前浏览器；可从航程菜单导出、导入。不同设备或网址不会自动同步。

本仓库为静态发布包；GitHub Pages 使用 main 分支根目录。更新 index.html 即可发布新版本。
