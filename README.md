# 漂流港 · Driftport

七章航行、两片开放海域与九重门藏。由数学与物理经典启发的探索游戏。

## 操作

- 电脑：WASD / 方向键驾驶，Space 交互，Shift 减速；鼠标拖镜、投信。
- 平板 / 手机：按住海面驾驶，触点离船越远越快；松手停船。轻点近处对象交互，轻点远处短途驶近。声纳轻点船身记录测线；拖镜片调整反射，轻点瞄准光点投信。建议横屏。
- 海图：点击图标可查看地名；点击下方地点名会在图上标出位置，再点“驶向所选地点”导航。
- 护航涂层：每层持续三分钟并减伤三分之一；不同商贩的效果线性叠加，三层免伤。买过的商贩会在本层到期前暂时停售。
- 暂停菜单可切换触控显示。手记、海图随剧情解锁。

## 存档

九艘船各有独立存档，进度保存在当前浏览器；可从航程菜单导出、导入所选船档。不同设备或网址不会自动同步。

本仓库为静态发布包；GitHub Pages 使用 main 分支根目录。发布时需同时更新游戏、缓存脚本、安装清单及图标。

## 安装与离线

Safari → 分享 → 添加到主屏幕（开启“作为网页 App 打开”，如有）。从桌面图标启动后独立运行。菜单“安装与离线游玩”显示离线资源状态。首次联网加载完成后可断网打开。新版下载好后点“保存航程并更新”；不会在航行途中自动刷新。

安装前可导出旧船档；若主屏幕版没有显示旧进度，请导入继续。浏览器清理网站数据或系统回收存储可能清除本地缓存和存档，请保留备份。

发布必须同时上传 index.html、sw.js、manifest.webmanifest 及 icons 目录；构建会自动更新缓存指纹。

## v1.17.0 · 海王纪

从海蛇隐藏事件开启的海怪剧情，包含骨翼穿越、海王愤怒、七船长大会、水母合奏、时间回拨及海怪纪元分支。极端结局中与巨鲸交谈后，二十种海洋生物开始全图漫游，带来240条原创自然、历史、语言与诗歌对白。港口建筑保留为人类遗址；此时海图只标海怪、海洋生物与隐舟。新增剧情进度和生物航迹随原船档保存。

## v1.17.1 · 开门后的海蛇

已开门并返回海面后，可以重新完成海蛇隐藏任务；三层护航涂层免伤仍可累计十五个鳞圈。完成后无穷号优先现身海蛇环心，既能开启显影及海怪剧情，也能记录本轮发现、选择下一周目。收起海蛇显影后，无穷号会恢复在正确层数的已开启门旁活动。旧船档无需重开。
